### UE5 import tips

1. **sRGB**: Color/Diffuse = sRGB; Normal, Roughness, AO, Displacement = Linear (no sRGB).
2. **Normals**: Poly Haven `nor_gl` and ambientCG `NormalGL` are OpenGL. In UE, if lighting looks inverted, use NormalDX or flip green channel.
3. **ARM pack** (models): R=AO, G=Roughness, B=Metallic — sample in material with ComponentMask.
4. **Displacement**: use for tessellation/virtual heightfield or as bump via cheap DeriveNormalZ; landscape prefers height as Landscape Layer.
5. **HDRI**: Place in `/Game/Tideborn/HDRI/`, assign to Skylight → Cubemap; Real-time Capture off when using static HDRI.
