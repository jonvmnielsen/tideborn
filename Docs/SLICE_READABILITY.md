# Slice readability — guidance ladder

Skill default: trust players; communicate with the world before GPS.

## Ladder (lowest that works)

1. **Silhouette / landmark / lighting funnel** ← current slice
   - Creature and resource meshes differ by shape/scale, not hue alone.
   - Shore Gate is a taller/wider vista with a bright **cyan** point light.
   - Path posts (`ATidebornLandmarkBeacon`) with tall thin mesh + **warm** light sit between PlayerStart and the gate.
2. **Audio beacon / ambient contrast** — not yet; optional next.
3. **Subtle diegetic markers** — name tags reinforce silhouettes (`Hostile` / `Tameable` / `Resource`); they never replace shape.
4. **Optional compass / trail** — accessibility only; not default.
5. **Hard GPS + VO** — avoid as default.

## Menus / juice
- Enter/exit at will (**I** / **B**); large hit targets; resume one action away.
- Craft feedback is a brief in-menu ping — does not replace or dismiss the inventory panel.
- Build = pick in menu, then LMB place while WASD+look.

## Verify in PIE
1. From spawn, spot warm path posts then cyan Shore Gate without opening a map.
2. Tell Burr-hound vs Kelp-back vs Wood vs Stone by silhouette at mid distance.
3. Open **I**, craft something — success line appears, menu stays; **I** closes.
4. Open **B**, click Foundation, place with LMB while moving.
