# Phase 1 — Camp (greybox)

## Controls
- **E** — Interact / gather (or place foundation while Build mode is on)
- **I** — Print inventory + recipes
- **C** — Craft first affordable recipe
- **B** — Toggle build mode (ghost foundation, snap 100uu)
- **F5** — Save inventory + placed foundations
- **F9** — Load

## Recipes
- Stick: 2 Wood
- Foundation: 5 Wood
- CampfireKit: 3 Stick + 2 Stone

## Map
Near PlayerStart: two Wood gather nodes + one Stone node (cube greybox).
